**Weather Wipe****Ｐ技後天気解除**_Remove Weather After Pokémon Uses Move_

**Passive Skill**

|     |     |
| --- | --- |
| Weather Wipe 1–8 |     |
| Has a chance (X%) of removing all weather conditions when the user's Pokémon uses a move. |     |
| Weather Wipe 9 |     |
| Removes all weather conditions when the user's Pokémon uses a move. |     |

**Weather Wipe** (Japanese: **Ｐ技後天気解除** _Remove Weather After Pokémon Uses Move_) is a family of [skills](https://bulbapedia.bulbagarden.net/wiki/Skill_(Masters) "Skill (Masters)")
 in [Pokémon Masters EX](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Masters_EX "Pokémon Masters EX")
.

Contents

Effect
------

When the [sync pair](https://bulbapedia.bulbagarden.net/wiki/Sync_pair "Sync pair")
's Pokémon uses a move, it has a chance of removing the any [weather](https://bulbapedia.bulbagarden.net/wiki/Weather_(Masters) "Weather (Masters)")
 condition currently applied to the field of play. The skill can range from Weather Wipe 1 to Weather Wipe 9, with higher numbered skills resulting in a greater chance of removing weather conditions. Weather Wipe 9 will always remove any weather condition. Currently, only Weather Wipe 9 is available on scoutable [sync pairs](https://bulbapedia.bulbagarden.net/wiki/Sync_pair "Sync pair")
.

| Skill rank | Activation chance |
| --- | --- |
| Weather Wipe 1 | 20% |
| Weather Wipe 2 | 30% |
| Weather Wipe 3 | 40% |
| Weather Wipe 4 | 50% |
| Weather Wipe 5 | 60% |
| Weather Wipe 6 | 70% |
| Weather Wipe 7 | 80% |
| Weather Wipe 8 | 90% |
| Weather Wipe 9 | 100% |
