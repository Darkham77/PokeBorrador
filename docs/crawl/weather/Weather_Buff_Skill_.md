**Weather Buff****天気変化時能力５種上昇**_Five Stats Boost When Weather Change_

**Passive Skill**

|     |     |
| --- | --- |
|     |     |
| The user's Attack, Defense, Sp. Atk, Sp. Def, and Speed increase 30% when weather conditions are in effect. |     |

**Weather Buff** (Japanese: **天気変化時能力５種上昇** _Five Stats Boost When Weather Change_) is a [skill](https://bulbapedia.bulbagarden.net/wiki/Skill_(Masters) "Skill (Masters)")
 in [Pokémon Masters EX](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Masters_EX "Pokémon Masters EX")
.

Contents

Effect
------

While any [weather](https://bulbapedia.bulbagarden.net/wiki/Weather_(Masters) "Weather (Masters)")
 condition is active on the battlefield, the user's [Attack](https://bulbapedia.bulbagarden.net/wiki/Stat#Attack "Stat")
, [Defense](https://bulbapedia.bulbagarden.net/wiki/Stat#Defense "Stat")
, [Sp. Atk](https://bulbapedia.bulbagarden.net/wiki/Stat#Special_Attack "Stat")
, [Sp. Def](https://bulbapedia.bulbagarden.net/wiki/Stat#Special_Defense "Stat")
, and [Speed](https://bulbapedia.bulbagarden.net/wiki/Stat#Speed "Stat")
 will each be increased by 30%.
