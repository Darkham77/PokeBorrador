# Purpose

Automation scripts for assets downloads, sprite conversion to WebP format, and spritesheets optimization.

## Child DOX Index

- [convert_assets.ts](./convert_assets.ts): Processes raw battle maps and sprites into optimized web formats.
- [download_assets.ts](./download_assets.ts): Fetches remote sprite sheets and assets datasets.
- [download_badges.ts](./download_badges.ts): Downloads official gym badge sprites.
- [optimize_sprites.ts](./optimize_sprites.ts): Compresses spritesheets by matching duplicate pixel buffers.
- [audit_item_assets.ts](./audit_item_assets.ts): Verifies physical webp item graphics integrity.
