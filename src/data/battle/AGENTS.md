# Purpose

Static battle datasets, move definitions, abilities, natures, and type matchups.

## Child DOX Index

- [abilities.ts](./abilities.ts): Pokemon abilities data.
- [moves.ts](./moves.ts): Move properties, power, accuracy, and categories.
- [natures.ts](./natures.ts): Stat modifiers per nature.
- [types.ts](./types.ts): Type effectiveness table.
- [volatileStatusMap.ts](./volatileStatusMap.ts): Volatile battle status configurations.
- [fx-configs.ts](./fx-configs.ts): Visual status/sprite FX configurations.
