# Purpose

Unit tests and regression suites for battle simulator helpers.

## Ownership

Systems Engineers / Backend Developers.

## Local Contracts

- Tests under this directory must execute successfully on Node.js using `node:test` (non-browser tests).
- Mock setups must use realistic inputs from `@pkmn/sim` and domain fixtures.

## Work Guidance

- Keep tests focused, clean, and decoupled from browser dependencies.

## Verification

- Run `npm run test` to execute these test suites.
