2. Paneles, Modales y Contenedores Nativos

Estructuras para aislar vistas, desplegables sin JavaScript y diálogos modernos.

details, dialog, popover, aside

<details> Acordeón Nativo (Con atributo name exclusivo)

Al compartir el atributo name="faq", abrir uno cierra automáticamente el anterior sin requerir librerías externas.

Panel 1: ¿Cómo funciona sin Javascript?
El navegador gestiona el estado binario (abierto/cerrado) internamente mediante el atributo booleano open. Es 100% accesible mediante la tecla Espacio o Enter.
Panel 2: ¿Qué es el atributo `name` en details?
Es la especificación oficial de acordeón exclusivo introducida recientemente en todos los motores modernos (Chromium, Firefox, WebKit). Garantiza que solo un panel esté abierto a la vez.
Panel 3: Personalización visual del Summary
Utilizando summary::-webkit-details-marker { display:none } ocultamos la flecha negra nativa para sustituirla con cualquier icono SVG personalizado.

Ventana <dialog> Nativa

Este panel modal se invoca con la API estándar dialog.showModal(). Proporciona de forma nativa:

  • Capa de oscurecimiento configurable mediante el pseudo-elemento ::backdrop.
  • Trampa de foco de accesibilidad para lectores de pantalla.
  • Cierre inmediato al pulsar la tecla Escape.

Popover API Oficial

Declarado simplemente con el atributo popover. Se posiciona en la capa superior (Top Layer) del navegador sin z-index hacks y se auto-cierra con "light dismiss".

Panel Lateral (<aside>)

El elemento semántico <aside> representa una porción de contenido tangencial al documento principal, ideal para barras laterales de herramientas, configuraciones o navegación secundaria.
